**HBE** is a project which actrually tracks the expenses of products used in a single house constructions.

<br>

# Installation

- Download nodemon globally
- Install `Open Terminal Programmatically` extenstions [Link](https://marketplace.visualstudio.com/items?itemName=open.in-terminal).
- Switch to `dev` branch.
- Go to `./` and run `npm install`
- Go to `./backend` and run `npm install`.
- Go to `./frontendend` and run `npm install`

<br>
<br>

# Run the application

The application is configured to run both frontend and backend under same terminal and under different terminals.

### Run both server under same terminal

- Go to `./` and run `npm run dev:con`;

### Run both server under different terminals

- Go to `./` and run `npm run dev`;
